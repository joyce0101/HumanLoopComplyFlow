# 页面切换到已实现接口

范围：页面固定调用 A 的预测与闸门、B 的持久化与指标、D 的报告接口，不再提供数据源切换。不修改现有模型、闸门、存储、指标实现，不重置现有数据库，不提交或推送。

1. 使用隔离数据库增加真实页面链路测试，覆盖默认数据源、批量保存、跨会话审批、modify、稀疏字段、失败保留输入、报告与下载。
2. Run Batch：显式运行时分别记录 prediction/gate。若第二次写入失败，预测保持 pending，提示部分成功，禁止显示为自动通过。
3. Review Queue：默认从 get_pending_reviews 读取，通过 submit_review 提交；不生成模拟申请。隐藏内部控制标记，缺失字段与空解释正常显示。modify 表示记录调整/暂缓请求，不提供条款编辑。
4. Dashboard/Compliance 默认接入现有接口；错误明确显示，不回退模拟数据。报告保留校验、配套快照校验与失败禁用下载逻辑。
5. 更新首页与报告中的过期来源描述。报告说明使用本地账本快照，无法自动证明历史数据来源；自动批准和拒绝分别统计。
6. 运行全部测试、独立代码审查，验证根数据库业务记录保持不变、受保护后端文件没有本任务的修改。所有写入验证使用临时数据库。

接口衔接：Prediction 与 GateResult 必须保持完整，持久化使用 dataclass 字典；审批沿用真实 case_id，页面使用统一公开别名避免泄露 GOLD 标记。prediction 和 gate 是两次独立事务，必须处理部分保存。
