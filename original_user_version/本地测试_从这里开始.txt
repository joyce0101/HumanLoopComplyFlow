LoopLedger — 强制登录 + 摄像头/鼠标验证版（本地测试）
==========================================

本次修复：默认 camera；必须先登录，再完成活体挑战才能进入任何业务页面。
直接打开 /Run_Batch 或其他页面也不能绕过认证。没有「off」模式。
旧环境变量 LOOPLEDGER_LIVENESS_MODE 不再控制开关。

Windows PowerShell（先进入压缩包中的 HumanLoopComplyFlow-main 文件夹）：

  py -3.11 -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install --upgrade pip
  python -m pip install -r requirements.txt
  python -m pip install -r requirements-verification.txt
  python scripts/download_liveness_model.py
  python -m pytest tests/test_liveness.py tests/test_reviewer_verification.py tests/test_workspace_access.py -v

为避免旧配置禁用验证，先显式设置 camera：
  $env:LOOPLEDGER_REVIEWER_VERIFY_MODE = "camera"

建议用独立数据库测试，原有数据库不会自动重置：
  $env:LOOPLEDGER_DB_PATH = Join-Path (Get-Location) "workspace-gate-local-test.db"
  python scripts/demo_reset.py --db $env:LOOPLEDGER_DB_PATH --empty

启动：
  python -m streamlit run app.py

操作顺序：
  1. 首页默认仅展示 Step 1 / 2：注册测试账号，Sign in 登录
  2. 自动进入 Step 2 / 2：勾选同意、Start new verification、摄像头 START
  3. 正视镜头；眨眼两次；向一侧转头回正；向另一侧转头回正
  4. 点击 Refresh verification status，看到 passed
  5. 点击 Finish verification and enter workspace
  6. 现在才可使用 Run Batch / Review Queue / Dashboard / Compliance
  7. Review Queue 提交每一条申请之前，还需再做该申请的活体挑战
  8. 右侧边栏 Log out 后必须重新登录和验证；20 分钟后需要重新活体验证

需要额外检测本机鼠标和屏幕轨迹时：
  Ctrl+C 停止 Streamlit
  $env:LOOPLEDGER_REVIEWER_VERIFY_MODE = "full"
  python -m streamlit run app.py

注意：full 只能在运行 Streamlit 的同一台 Windows 电脑上采集鼠标和屏幕。
这是本地原型，不是实名人脸核验或安全级防伪系统。屏幕/鼠标检测结果也不是人类身份的证明。
摄像头和 WinRT 实机效果需在你的 Windows 电脑上验证。

新增测试 test_workspace_access.py 覆盖未登录拦截、登录但未验证拦截、
临时凭证签名、换账号/会话和过期失效、所有页面入口检查。
全部已通过源码编译，硬件端未在此容器实测。
